# Пилот на разбиении C (seed 42)

Источники: `derived\results_pilot_C_tfidf.csv`, `derived\results_pilot_C_gine.csv`. Настройки и пороги выбраны на val, метрики посчитаны на test один раз. Пилот реализуемости: одно разбиение, без выводов о значимости.

Разбиение C_seed42: train / val / test = 1534 / 512 / 512, уникальных трасс в test 322; крупнейшая группа test — 84 строк (32.8% своего класса в test).

## Метрики: все строки test

- `mcc`, `f1` — при пороге, выбранном по MCC на val
- `pr_auc`, `roc_auc` — от порога не зависят
- `fpr_at_tpr95` — доля benign, ложно отмеченных как malware, при пороге, который на val ловит 95% malware (меньше = лучше)
- `train_sec` — время обучения, секунд (у TF-IDF — вместе с подбором C по val, у GINE — 40 эпох с оценкой на val)
