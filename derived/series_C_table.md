# Полная серия C (seed 42–46)

Seed 42 — пилот (04.11), seed 43–46 — серия. Настройки и пороги выбраны на val, test посчитан один раз. Среднее ± std (ddof=1) по пяти seed.

## Проверки

- `tfidf_logreg`: настройки всех пяти seed совпадают с пилотом; файлы разбиений не менялись
- `gine_e40`: настройки всех пяти seed совпадают с пилотом, везде CPU; файлы разбиений не менялись
- MCC, пересчитанный по сохранённым предсказаниям, совпадает с файлами результатов у всех 10 запусков
