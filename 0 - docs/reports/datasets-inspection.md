Дата: 2026-10-24. Все цифры посчитаны мной на **выборках**, скачанных из источников (файлы только читались как текст, не запускались). Это не полные наборы, поэтому цифры приблизительные, особенно там, где выборка мала.

## Quo Vadis / Speakeasy
- **Состав подтверждён по списку файлов:** 92 703 файла, benign 32 673 (35%), 7 семейств malware. В README написано 93 533 и 76 126 в обучающей части, реально 75 301: README устарел.
- **Дрейф:** обучающая часть собрана в январе 2022, тестовая в апреле 2022. Это окно всего три месяца.
- **Трассы короткие:** медиана около 180 вызовов, максимум **ровно 501**. Это жёсткий предел эмулятора, а не свойство программ. Для идеи про длинные трассы набор не подходит.
- **Много дубликатов:** в выборке из 589 файлов только 311 уникальных последовательностей имён API (47% дублей). Дроппер медианно имеет 22 вызова, системные benign из `syswow64` — 8.
- **Shortcut есть:** по первым 10 вызовам AUC 0,906 (на выборке, сплит случайный); по полной трассе 0,927; только по длине 0,635; обучение на выборке января и проверка на апреле даёт 0,887.
- **Аргументы есть** (`pc`, `api_name`, `args`, `ret_val`), но нет времени.

## DataCon 2019 Stage1
- **Состав подтверждён:** `train/white` 20 000 и `train/black` 10 000, метки в `safe_type_train.csv` совпадают с папками; плюс 15 000 файлов теста без меток. Лицензии нет.
- **Формат описан в самом репозитории:** для каждого вызова указаны `api_name`, `call_pid`, `call_name`, `call_time` (с миллисекундами), `ret_value`, аргументы `apiArg` и дополнительные строки `exInfo` (пути, имена). Есть разделы `start_boot` и `reboot`.
- **Сильный shortcut по длине:** benign медианно 128 вызовов (23% короче 50), malware **4 026** (81% длиннее 1 000). Классификатор только по числу вызовов даёт **AUC 0,903**, только по размеру файла 0,906. Размеры во всём репозитории подтверждают это: медиана 39 КБ у benign против 1,1 МБ у malware.
- **Процессы:** у malware медианно 8 процессов и 34 PID, у benign 2 и 2. Это тоже сильный признак среды запуска, но реальное поведение.
- **Остальное:** первые 10 вызовов дают AUC 0,669 (слабый shortcut), первые 100 — 0,922, полная трасса — 0,965. В выборке 265 уникальных трасс из 300.
- **Среда:** процессы называются `1.exe`, а пути `C:\program\1.exe`, то есть образцы переименованы — артефактов имени нет. Системные пути `C:\WINDOWS\system32` указывают на старую Windows. Раздел `reboot` есть у 39% malware и у 1% benign.
- **Проверить:** оба класса выполняются около 5 минут.

## Fellicious
- **Файл меток** `shas_by_families.json`: 264 «семейства» вместе с `benign`; всего 339 153 записей, из них **benign 9 621** (не 10 000), malware около 329 500. **4 549 хэшей встречаются в нескольких семействах**, то есть метки неоднозначны.
- **Перекос по семействам:** три семейства (soltern 58,7 тыс., vobfus 57,3 тыс., eggnog 31,4 тыс.) дают около 45% malware. В моей выборке топ-3 — 46%.
- **Архив отсортирован по хэшу**, поэтому начало архива — случайная выборка. 60 МБ сжатых данных дают 4 ГБ распакованных (2 177 файлов, сжатие примерно в 66 раз).
- **Формат:** JSON Lines. Каждый вызов записан **двумя строками** (`hookCallback hit` и `Monitored function called`), реальных вызовов в два раза меньше строк. Шум «Could not trace function» — всего **0,1%** строк (прежняя оценка «половина строк» была по двум файлам и неверна).
- **Длины:** медиана около 2 000 вызовов, максимум около 13 600. Не очень длинные, но заметно длиннее, чем у Quo Vadis. Пустые трассы: 5% у benign и 1% у malware.
- **Словарь маленький:** 53 функции ntdll. Самые частые: `LdrGetDllHandle`, `NtClose`, `NtProtectVirtualMemory`, `NtQueryValueKey`.
- **Параметры почти бесполезны:** в одном просмотренном файле строки пустые (`"ObjectName":""`, `"ModuleFileName":""`), а числа выглядят как мусор (например, `DesiredAccess = 7311855404974112`). Это значит, что аргументы, на которых строится часть вашей идеи, здесь не несут смысла. Проверен один файл, нужно подтвердить на нескольких.
- **Время** с шагом 1 секунда, у трассы около 184 разных меток времени.
- **Shortcut по длине слабый** (AUC 0,60), по первым 10 вызовам 0,61. Но по **первым 100** вызовам AUC уже **0,979**, по полной трассе 0,983. Benign в выборке всего 56, поэтому цифры шумные; вероятно, benign (службы Microsoft без GUI) легко отличаются от доминирующих семейств по типичному началу трассы.

## Выводы
1. **Для идеи «длинные трассы с аргументами» не подходит ни один из трёх.** Quo Vadis: до 501 вызова, эмуляция. Fellicious: ~2 000 вызовов, но параметры бесполезны. DataCon: трассы длинные (медиана 4 026 у malware), аргументы и время есть, но это старый набор и сильный shortcut по длине.
2. **DataCon 2019 по полям — лучший из трёх:** порядок, аргументы, `exInfo` с путями, PID, миллисекунды, два класса с нормальным балансом. Проблема — класс почти определяется по длине трассы (AUC 0,90), и нужно решить, как с этим жить: усечь все трассы до одной длины, подбирать пары по длине, или использовать как «трудный» тест. Среда устарела, лицензии нет.
3. **Fellicious полезен как большой корпус для предобучения** и как dataset с реальной Windows 10, но не как источник осмысленных аргументов. Годится для проверки «порядок вызовов ntdll», если не ждать параметров.
4. **Quo Vadis** хорош как готовая отправная точка с числами Nebula, но только для коротких трасс.
5. **Общее:** на всех трёх простая модель TF-IDF + LogReg даёт AUC 0,93–0,98. Любая новая модель должна побить этот baseline.

## Ограничения этой проверки
- Выборки: 589, 300 и 2 177 файлов; для Fellicious benign только 59 файлов.
- Кросс-валидация случайная, без дедупликации по семействам, поэтому AUC завышены.
- DataCon выборка берётся из обучающей части, benign и malware по 150 случайных файлов.
- Параметры Fellicious просмотрены на одном файле.
- Скрипты анализа (`stats.py`) лежат во временной папке сессии и в репозиторий не добавлены.
