## Для вторичных экспериментов
- **COMISET** (Zenodo 15375145, CC BY 4.0): ~252 млн событий Sysmon, но malicious всего ~0,9%. Годится для предобучения, не для классификации.
- **CSU-Ransomware-Data**: 413 556 событий Sysmon, но признаки уже обработаны и дрейф искусственный.
- **LAMDA** (Hugging Face, MIT, 2013–2025): готовый тест на дрейф для conformal, но признаки статические и подходят не для последовательностной модели.
- **CICMalDroid 2020**: syscalls Android, но это частотные таблицы, а не последовательности.
- **ADFA-LD / ADFA-WD**: только проверка работоспособности, это не malware, а вторжения.
- **Не подходят:** CICAndMal2017 (только трафик), MalVol-25 (дампы памяти), ForensicsData (1500 отчётов), SecureCorpus (платный).
- **ETW-наборов** с benign и malware найти не удалось.

## Свой прогон через CAPE
- CAPEv2 рассчитан на нативный Linux-хост (Ubuntu LTS). Для вас реалистичнее dual-boot Ubuntu, чем вложенная виртуализация (мой вывод).
- Оценка времени (моя, не из источников): при ~3 параллельных VM около 55–70 образцов в час, то есть 2000–5000 образцов — примерно 30–90 часов чистого времени. Стоимость почти нулевая, если свой компьютер.
- Условия использования Hybrid Analysis, Tria.ge, ANY.RUN, VirusTotal проверить не удалось. Для ANY.RUN доступ к API, судя по вторичным источникам, платный.
- Список источников benign (Chocolatey, winget, NSRL и т. д.) в поиске не подтверждён.

## Вывод
**Идеального набора нет.** Лучший реальный вариант — Fellicious: реальная VM, порядок, параметры и время, свободная лицензия. Но его benign сильно отличается от malware (без GUI, 3%), поэтому первым делом нужен тест на shortcut: классификатор только по длине, только по первым вызовам и по признаку «есть ли GUI-функции». Для предобучения его 330 тыс. malware очень полезны. Если нужен чистый benign, самый надёжный путь — собственный прогон через CAPE.

## Что делать дальше
1. Скачать только маленькую часть Fellicious (архив можно читать по частям, исследователь так и сделал) и посчитать длины трасс и долю шума.
2. Открыть benign-файл DataCon 2019 и убедиться, что он сопоставим с malware по формату.
3. Написать авторам Ilić et al. и спросить про данные.
4. Проверить, скачиваются ли данные DMBD.
