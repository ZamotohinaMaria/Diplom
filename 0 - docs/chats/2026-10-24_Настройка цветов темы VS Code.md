Нужно сделать из вашей копии темы маленькое локальное расширение. Тогда она будет отдельным пунктом в списке тем, и переключаться можно будет как между обычными темами.

**1. Структура папки**

Создайте папку, например `C:\Users\Marishka\.vscode\extensions\marishka.horla-custom-0.0.1\`, а в ней:

```
marishka.horla-custom-0.0.1\
├── package.json
└── themes\
    └── Horla-custom-color-theme.json   ← ваша копия с правками
```

**2. package.json**

```json
{
  "name": "horla-custom",
  "displayName": "Horla Custom",
  "version": "0.0.1",
  "publisher": "marishka",
  "engines": { "vscode": "^1.22.0" },
  "categories": ["Themes"],
  "contributes": {
    "themes": [
      {
        "label": "Horla Custom",
        "uiTheme": "vs",
        "path": "./themes/Horla-custom-color-theme.json"
      }
    ]
  }
}
```

`uiTheme` — это `vs` для светлой темы и `vs-dark` для тёмной. Значение `label` — название, под которым тема появится в списке.

**3. Подключение**

Перезапустите VS Code (или выполните `Developer: Reload Window`). Потом нажмите `Ctrl+K Ctrl+T`, и в списке будет **Horla Custom**.

**Как переключаться**
- `Ctrl+K Ctrl+T` и выбор любой готовой темы. Ваша остаётся в списке.
- Чтобы вернуться, откройте то же меню и выберите **Horla Custom**.
- Оригинальный Horla не затрагивается, так что можно сравнивать обе версии.

**Важно**
- Свою тему правьте только в её файле, не в копии внутри расширения Horla. Тогда обновления оригинала её не сотрут.
- После правки файла темы достаточно переключиться на другую тему и обратно, перезапуск не нужен.
- Файл темы лучше хранить и в проекте или в git как резервную копию. Папка `.vscode\extensions` легко теряется при переустановке.

Да, помню, и ты права: чёрные блоки можно убрать прямо в теме. PowerShell красит вставленный текст белым на чёрном, а эти два цвета берутся из палитры терминала темы. Поменяю их там.

Я поправила тему в [Horla-custom-color-theme.json](../marishka.horla-custom-0.0.1/themes/Horla-custom-color-theme.json), в блок терминала добавила три цвета. Тему с этой правкой я не запускала, поэтому исчезнут ли чёрные блоки, пока не проверено.

- `terminal.ansiBlack` теперь `#F0F0F0`, как фон терминала. Чёрная подложка под текстом сольётся с фоном и исчезнет.
- `terminal.ansiWhite` и `terminal.ansiBrightWhite` теперь `#383a42`. Иначе белый текст (раньше `#E0E0E0`) стал бы невидимым на светлом фоне.

Побочный эффект: программы, которые выводят «чёрный» или «белый» через ANSI, будут показывать светло-серый и тёмно-серый. На светлой теме это даже логично.

Чтобы увидеть результат, скопируйте обновлённую папку расширения в `.vscode\extensions` (заменив старую), перезапустите VS Code и выберите тему **Horla Custom** (как мы делали раньше). Если часть текста всё равно останется чёрной, пришлите скриншот: возможно, это другой ANSI-цвет и я поправлю и его.
