Начну с основных обзорных документов.

**Лучший кандидат на второй датасет — DataCon 2019 Stage1.** Твой руководитель тоже называл именно его, когда планировал неделю 5.

## Почему DataCon подходит для экспериментов 4 и 5

| Что нужно для переноса | DataCon 2019 Stage1 |
|---|---|
| Есть оба класса | да: 20 000 benign и 10 000 malware в train, метки совпадают с папками |
| Имена API, а не id | да: `api_name` в XML, поэтому словарь можно сопоставить с MalBehavD-V1 |
| Порядок вызовов | да, значит можно строить граф для GINE |
| Доступ | открытый GitHub, качается сразу |
| Объём | 30 000 размеченных трасс, хватит и на дообучение, и на валидацию |

Для эксперимента 5 (проверка без дообучения) главное — общий словарь API. Модель, обученная на MalBehavD, должна узнавать токены нового набора. У DataCon это возможно: там Win-API по именам.

## Риски, которые нужно учесть заранее

1. **Пересечение словарей не посчитано.** В DataCon около 77 API, в MalBehavD 291. Если общих имён мало, TF-IDF и GINE увидят почти одни неизвестные токены, и качество без дообучения упадёт до случайного. Это первое, что нужно посчитать. Даже плохой результат будет выводом для RQ3.
2. **Класс сильно угадывается по длине трассы.** У benign медиана 128 вызовов, у malware 4 026; один только признак длины даёт AUC 0,90. У MalBehavD длина не больше 175. Я бы обрезал трассы DataCon до той же длины (например, первые 175 вызовов). Тогда модели будут сравниваться на сопоставимом входе, а подсказка по длине исчезнет.
3. **Среда старая** (похоже на Windows XP), песочница не названа, лицензии нет. Это нужно упомянуть в тексте как ограничение.
4. **Дубли.** В выборке 265 уникальных трасс из 300, это меньше, чем у MalBehavD. Но дедупликацию по хэшу до разбиения всё равно нужно делать, как в H1.

## Почему не другие

- **Quo Vadis / Speakeasy** — запасной вариант. Классы есть, лицензия Apache-2.0, объём большой. Но трассы получены эмуляцией, а не в песочнице, обрезаны на 501 вызове, и дублей около 47%. Разница среды с MalBehavD будет ещё больше.
- **Oliveira (Kaggle)** указан в плане как вариант, но API там закодированы числами 0–306 без имён. Словари не сопоставить, поэтому эксперимент 5 бессмыслен.
- **Fellicious** записывает только 53 функции ntdll, и benign там всего 3%. С MalBehavD пересечение будет минимальным.
- **AutoRobust** хранит множества строк без порядка, поэтому для GINE не подходит.
- **Avast-CTU и WinMET** содержат только malware, бинарную задачу на них не поставить.
- **DMalNet demo** — готовые графы без исходных трасс. **CIC-MalMem** — признаки дампа памяти, а не API.
- **Mal-API-2019** упомянут в плане, но в доках не проверялся. Насколько я знаю, там только malware восьми семейств без benign. Если это так, для бинарного переноса он не подходит.

**Следующий шаг:** скачать DataCon Stage1, извлечь `api_name` и посчитать пересечение словаря с 291 API из MalBehavD. От этой цифры зависит, получится ли эксперимент 5 осмысленным. Могу написать скрипт для этого, запустишь его сама.

Обе ссылки взяты из твоих отчётов в `0 - docs/reports/`.

**DataCon 2019 Stage1** (GitHub):
https://github.com/kericwy1337/Datacon2019-Malicious-Code-DataSet-Stage1

- В репозитории около 45 000 файлов, поэтому удобнее скачать его ZIP-архивом (Code → Download ZIP). Можно и через `git clone --depth 1 <ссылка>`, тогда без истории коммитов будет быстрее.
- Метки лежат в `safe_type_train.csv`, трассы — в `train/white` и `train/black`.
- Есть ещё Stage2 (https://github.com/kericwy1337/Datacon2019-Malicious-Code-DataSet-Stage2), но там только malware с семействами, тебе он не нужен.

**AutoRobust** (Kaggle, набор «Malware & Goodware Dynamic Analysis Reports»):
https://www.kaggle.com/datasets/greimas/malware-and-goodware-dynamic-analysis-reports

- Для скачивания нужен вход в Kaggle. Либо кнопка Download на странице, либо через CLI: `kaggle datasets download greimas/malware-and-goodware-dynamic-analysis-reports`.
- Архив около 206 МБ, лицензия CC BY-SA 4.0.
- Напомню: в его JSON есть только `summary`, то есть множества строк без порядка вызовов. Для GINE он не подойдёт, только для baseline на множествах.

### 🤖 Claude  <sub>2026-11-14 19:29</sub>

Сам репозиторий весит около **0,9 ГБ**. Это поле `size` из GitHub API, 956 002 КБ. Столько примерно и придётся скачать, ZIP-архив будет похожего размера.

После распаковки места понадобится заметно больше. По выборке из отчёта медианная трасса malware занимает 1,1 МБ, benign — 39 КБ. Тогда 10 000 malware — это порядка 10 ГБ, плюс около 1 ГБ на benign и сколько-то на тест. Git хранит файлы сжатыми, а XML сжимается хорошо, отсюда и разница с 0,9 ГБ. Это оценка по медианам, точную цифру я не проверял. На диске лучше держать свободными **15–20 ГБ**.

Если места мало, можно не распаковывать всё. Скрипт может читать XML прямо из ZIP-архива и сохранять только последовательности `api_name` в CSV.
