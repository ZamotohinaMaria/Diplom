В VS Code есть три способа выгрузить чаты Claude Code. Для всех чатов сразу удобнее первый.

## Способ 1. Все чаты сразу (скрипт)

1. Откройте терминал в VS Code: **Terminal → New Terminal** (или `` Ctrl+` ``).
2. Проверьте, что вы в папке `Diplom`, и выполните:
   ```
   python "0 - docs/export_chats.py"
   ```
3. Готовые файлы появятся в `0 - docs/chats/`, по одному `.md` на каждый чат.

## Способ 2. Один конкретный чат (команда `/export`)

1. В терминале VS Code запустите:
   ```
   claude --resume
   ```
2. Стрелками выберите нужный чат из списка и нажмите Enter.
3. Введите команду:
   ```
   /export
   ```
4. Выберите, куда сохранить: в буфер обмена или в текстовый файл.
5. Выйдите командой `/exit`.

Если `/export` сработает прямо в окне чата расширения, можно обойтись без терминала. Но через терминал этот способ работает точно.

## Способ 3. Исходные файлы вручную

Сырые файлы всех чатов этой папки лежат здесь:
```
C:\Users\Marishka\.claude\projects\c--Users-Marishka-Desktop-code-Diplom\
```

**Важно:** удалять или переносить файлы из этой папки нельзя, иначе Claude Code потеряет историю чатов. Только копировать.

### 🤖 Claude  <sub>2026-11-15 09:40</sub>

Каждый запуск скрипта заново читает все чаты и пересоздаёт файлы с нуля, поэтому обычный повторный запуск безопасен.

| Что произошло | Что сделает скрипт |
|---|---|
| В старом чате появились новые сообщения | Перезапишет его `.md` целиком, с новыми сообщениями |
| Появился новый чат | Создаст для него новый `.md` |
| Ничего не изменилось | Перезапишет файлы тем же содержимым |

Вручную ничего чистить не нужно, достаточно просто запускать скрипт ещё раз.

## Есть два слабых места

**1. Могут появляться дубли.** Имя файла строится из даты и названия чата. Название Claude Code придумывает сам и иногда меняет по ходу разговора. Если оно изменится, скрипт создаст файл с новым именем, а старый так и останется лежать. Это можно исправить: добавить в имя короткий номер сессии, например `2026-10-24_Чистка репозитория_f7977131.md`. Тогда у каждого чата будет одно постоянное имя, и при смене названия старый файл будет заменяться, а не копиться.

**2. Claude Code сам удаляет старые чаты.** По умолчанию он стирает чаты старше 30 дней. Ваш первый чат от 24 октября уже близок к этому сроку. Уже выгруженные `.md` останутся, скрипт их не трогает. Но выгрузить заново или дополнить удалённый чат будет уже нельзя. Срок хранения можно увеличить в настройках, например до года: это параметр `cleanupPeriodDays` в `C:\Users\Marishka\.claude\settings.json`.

Если хотите, сделаю оба исправления: поменяю имена файлов в скрипте и увеличу срок хранения чатов в настройках.
