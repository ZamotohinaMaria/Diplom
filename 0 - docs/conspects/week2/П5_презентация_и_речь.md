## Речь

Чтобы это проверить была выдвинута гипотеза: если копии одной API-трассы попадают и в обучающую, и в тестовую выборку, модель частично проверяется на уже знакомых примерах, и метрики качества оказываются завышенными. Проверка заключается в следующем: если при случайном разбиении (A) метрики выше, чем при разбиении без общих трасс (B), и разница превышает разброс между повторными разбиениями, то результаты научной работы завышены.

# Приложение. Короткие ответы на вероятные вопросы

Пункт 6 задания: уметь объяснить эти вещи.

- **Трасса и файл.** Файл — исполняемая программа, её идентификатор — `sha256`. Трасса — последовательность API-вызовов одного запуска файла в песочнице. Один файл при повторном запуске может дать разные трассы, а разные файлы — одинаковую трассу (группа из 164 строк — это 162 разных файла).
- **A, B, C.** A — случайное разбиение по строкам, копии трасс есть и в обучении, и в тесте. B — все копии одной трассы в одной части. C — дополнительно все трассы одного файла в одной части, то есть тест состоит только из новых файлов.
- **Почему не `StratifiedGroupKFold`.** Из-за крупных групп (164, 84, 52 строки) он давал test от 411 до 717 строк и долю malware от 35 до 68 %; тогда A и B различались бы ещё и размером и балансом. Поэтому группы раскладываются жадно (LPT) внутри каждого класса: крупные первыми, в наименее загруженный фолд.
- **Почему метрики НИРС, вероятно, оптимистичны.** В схеме НИРС у 41,8 % оценочных строк была точная копия в обучении (у malware — 68,1 %, у benign — 15,6 %), не было validation, порог был фиксирован 0,5. Насколько завышены именно числа НИРС, отдельно не измерялось.
- **Validation и test.** На validation выбираются параметр C логистической регрессии, эпоха и температура GINE, порог классификации. Test не участвует ни в одном выборе и считается один раз.
- **MCC.** Коэффициент корреляции Мэтьюса учитывает все четыре клетки матрицы ошибок, от −1 до 1, 0 — уровень случайного угадывания. Выбран как основная метрика, потому что одним числом отражает и пропуски, и ложные тревоги.
- **Ограничения пяти повторений.** Это пять разных seed, в каждом используется один фолд test; test-части разных seed пересекаются (в среднем около 100 строк из 512). Стандартное отклонение показывает чувствительность к разбиению, а не точность среднего. p-значения t-теста Уэлча — только ориентир: наблюдения не независимы, n = 5, сравнений много.
- **Новые файлы — не новые семейства.** C гарантирует, что файлов test нет в train, но похожие трассы файлов одного семейства могут быть в обеих частях; сведений о семействах в датасете нет.
- **Почему GINE хуже по ложным тревогам.** На уникальных трассах обе модели пропускают 12 из 97 вредоносных трасс, но GINE ложно отмечает 11 из 225 benign, TF-IDF — 2. Причины (хуже отделяет редкое benign-поведение, калибровка) — гипотезы, не проверялись.
