| Модель | A, все строки | B, все строки | A, уник. трассы | B, уник. трассы |

- Почему уникальные трассы: в B крупная группа может занять до 64 % malware test (seed 44, группа из 164 строк), и метрика по всем строкам во многом отражает ответ на одну трассу

## Речь

В таблице — коэффициент корреляции Мэтьюса для двух моделей: логистической регрессии на TF-IDF по n-граммам вызовов и графовой нейросети GINE. Значения — среднее и стандартное отклонение по пяти повторным разбиениям. Оценка дана по всем строкам теста и по уникальным трассам, где каждая трасса учитывается один раз. Это важно: в одном из разбиений B группа из 164 одинаковых трасс заняла почти две трети вредоносной части теста. У обеих моделей A выше, чем B. По всем строкам разница меньше разброса, на уникальных трассах больше и сравнима с ним. Поэтому я описываю это как чувствительность оценки к протоколу: направление согласуется с гипотезой о завышении, но строгим подтверждением не считаю. Причина не только в дублях: в B меняются и состав теста, и вес крупных групп. Разбиения пересекаются, поэтому p-значения — только ориентир. И главное по моделям: превосходство GINE над сильной классической моделью не показано.

# Приложение. Короткие ответы на вероятные вопросы

Пункт 6 задания: уметь объяснить эти пять вещей.

- **Трасса и файл.** Файл — исполняемая программа, её идентификатор — `sha256`. Трасса — последовательность API-вызовов одного запуска файла в песочнице. Один файл при повторном запуске может дать разные трассы, а разные файлы — одинаковую трассу (группа из 164 строк — это 162 разных файла).
- **A, B, C.** A — случайное разбиение по строкам, копии трасс есть и в обучении, и в тесте. B — все копии одной трассы в одной части. C — дополнительно все трассы одного файла в одной части, то есть тест состоит только из новых файлов.
- **Почему не `StratifiedGroupKFold`.** Из-за крупных групп (164, 84, 52 строки) он давал test от 411 до 717 строк и долю malware от 35 до 68 %; тогда A и B различались бы ещё и размером и балансом. Поэтому группы раскладываются жадно (LPT) внутри каждого класса: крупные первыми, в наименее загруженный фолд.
- **Почему метрики НИРС, вероятно, оптимистичны.** В схеме НИРС у 41,8 % оценочных строк была точная копия в обучении (у malware — 68,1 %), не было validation, порог был фиксирован 0,5. Насколько завышены именно числа НИРС, отдельно не измерялось.
- **Validation и test.** На validation выбираются параметр C логистической регрессии, эпоха и температура GINE, порог классификации. Test не участвует ни в одном выборе и считается один раз.
- **MCC.** Коэффициент корреляции Мэтьюса учитывает все четыре клетки матрицы ошибок, от −1 до 1, 0 — уровень случайного угадывания. Выбран как основная метрика, потому что одним числом отражает и пропуски, и ложные тревоги.
- **Ограничения пяти повторений.** Это пять разных seed, в каждом используется один фолд test; test-части разных seed пересекаются (в среднем около 100 строк из 512). Стандартное отклонение показывает чувствительность к разбиению, а не точность среднего; строгой статистической значимости не заявляется.
