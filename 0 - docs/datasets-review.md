## 1. Почему MalBehavD-V1 не годится как основной

| Проверка | Результат |
|---|---|
| Уникальных последовательностей malware | **479 из 1285** (63% дублей) |
| Уникальных последовательностей benign | 1123 из 1285 |
| После дедупликации | 1601 образец, malware 30% |
| TF-IDF(1–2-граммы) + LogReg, 5-fold, с дублями | AUC 0,987, F1 0,951 |
| То же после дедупликации | AUC 0,965, **F1 0,858** |
| Только первые 10 вызовов | AUC **0,968** |
| Только длина и число уникальных API | AUC 0,495 |
| Длина последовательности | медиана 37, максимум 175 |
| Словарь | 291 API |

Выводы:
- **Утечка.** Дубли попадают одновременно в train и test, поэтому все прошлые метрики (GINE ~97–98%, классификация синтетики) завышены.
- **Shortcut.** Класс почти полностью определяется по первым 10 вызовам. Скорее всего, это артефакты сбора: benign — установщики с CNET, malware — с VirusTotal, условия песочницы разные. Модель учится отличать источники, а не поведение.
- **Бедные данные.** Нет параметров вызовов, дерева процессов, семейств и времени.
- **Что делать с ним дальше:** использовать только как маленький контрольный набор и только после дедупликации.

## 3. Чек-лист «нормального» датасета

Прогонять на каждом кандидате:

1. Дедупликация по хэшу последовательности **до** разбиения на выборки.
2. Сплит по семейству и/или по времени, а не случайный.
3. benign и malware собраны в одной песочнице и в один период.
4. Контрольные baseline: первые k вызовов, длина, n-gram LogReg. Если простая модель даёт AUC ≈ 0,97, датасет подсказывает ответ.
5. Нет противоречивых меток (одна последовательность в обоих классах).

## 4. Заметки про GATv2 и GraphSAGE

- **На цепочках i→i+1 почти бесполезны.** У узла 1–3 соседа, и attention вырождается. Смысл появляется на богатых графах: гетерограф процесс → API → ресурс или граф переходов API (узел = уникальный API, ребро = переход с частотой).
- **GATv2Conv** принимает признаки рёбер (`edge_dim`), поэтому почти заменяет GINE без переделок.
- **SAGEConv** признаки рёбер не принимает. Нужен `to_hetero` или кодирование рёбер через узлы.
- **Сравнивать только на одном протоколе.** Удобнее всего флагом `--conv gine|gatv2|sage`.
- **Любая GNN должна побить n-gram LogReg** (AUC 0,965 после дедупликации), иначе граф не оправдан.
